web-page-builder · taste library

Intake

Drop URLs in. They become records the harvester can run against on a machine with open web access — which is where the screenshot, palette and fonts get filled in. This page collects; it does not fetch.

Paste anything with links in it

A line like Name — url keeps the name. A bare URL takes its domain as the name. Duplicates are dropped on the way in.

The library

Take it back to the machine that can fetch

Drop that file at skills/web-page-builder/library/candidates.json, then:

python3 tools/harvest_site.py --pending python3 tools/build_gallery.py

The harvester walks every record that has a URL and is still pending, pulls the screenshot, palette and fonts, and rebuilds the gallery from what it found.

Why there are no thumbnails here

A published page can't reach other websites — no fetching, no remote images. So this page can't screenshot anything, and any preview it showed you would be invented. Collecting is the half that works here; fetching is the half that works on your laptop. Nothing is stored on a server either — download the file when you're done, and import it to pick up later.
